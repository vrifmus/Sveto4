# Sveto4: правила проекта

Общие правила лежат в `~/.claude/CLAUDE.md`, описание проекта в `README.md`.

@docs/ROADMAP.md

## Безопасность (файрвол)

- Не запускать `sveto4.ps1`, `sveto4.exe`, `run.vbs`, `convert_to_exe.ps1` без явного разрешения пользователя.
- Не выполнять команды, меняющие файрвол (`Set-/New-/Remove-/Enable-/Disable-NetFirewall*`, `netsh advfirewall set|add|delete|reset`), без явного разрешения. Читать настройки (`Get-NetFirewall*`) можно.
- Перед экспериментами с файрволом предложить резервную копию: `netsh advfirewall export "<путь>\backup.wfw"`.

## Код

- Целевая среда: Windows PowerShell 5.1, WinForms; скрипт работает с правами администратора.
- Имена функций в стиле PowerShell (Verb-Noun).
- Все правила файрвола, которые создаёт программа, называются с префиксом `KS-` (`$RulePrefix`), чтобы «Reset ALL» мог их найти и удалить.

## После изменений

- После правок `sveto4.ps1` напомнить пересобрать `sveto4.exe` через `convert_to_exe.ps1`.
- Известная проблема: собранный exe выдаёт ошибку после выхода компьютера из сна, а скрипт, запущенный напрямую, работает стабильно. Обсуждается переход интерфейса на другую технологию (см. `docs/ROADMAP.md`).
